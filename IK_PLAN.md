- **Phase 1 done (no spend), then hardened after an adversarial review.** `goodlaw/ik.py` (the client), `test_goodlaw_ik.py` (a fake local server and an injected transport; no real call) and `python sci_goodlaw.py ik status|plan|run|confirm`. The module docstring lists every guard; in short: the key comes from the environment only, is scrubbed from every file and message and goes only to `api.indiankanoon.org` (redirects are never followed); `plan` prints each call, its price and a **plan id**, and `run` refuses unless `--approved-rs` equals the cost *and* `--plan-id` matches (an approval cannot be reused for another list); `--run-cap` must be a finite number; a hard total of Rs 150 across runs is remembered in the committed ledger `goodlaw/data/ik_ledger.jsonl` (no key, no IK text), which the CLI requires to exist and cannot be pointed elsewhere; **the attempt is written to the ledger before the call is sent**, so a crash or a failed write never leaves a charged call unrecorded, and a call with no result counts as spent; any error other than 401/402/403/429 also counts as spent (it may be charged); the first error of any kind ends the run, with no retry, and the same call is refused again unless `--retry-failed`; a 200 answer is a success only if it is a non-empty JSON object without an `errmsg`, `error`, `errors`, `message` or `detail` field (and `meta` has the real fields, `search` a `docs` list), and a refused answer is kept in `ik_cache/_rejected/` so IK's real error shapes can be read; **a kind of call (a "shape": the kind plus its extra parameters and their values) can be planned as one call only until the owner has read the dashboard price and recorded it with `ik confirm --shape ... --price ... --note ...`**; the cache is git-ignored and does not survive a session, so a call the ledger says was paid for but the cache lacks is refused unless `--refetch` (the Phase 0 answer is committed as a sample, so it is never re-bought); one run at a time (lock file); serial calls 0.5 s apart; the answer is read with a size limit and an overall deadline and decoded as UTF-8; an `IK_STOP` file in the repository or working folder refuses every call. The Phase 0 call is in the ledger with the owner's price confirmation (Rs 0.02 spent so far by this client; `meta` is the only confirmed shape).
- **How it was checked.** Four independent reviewers (spending, key safety, failure handling, tests and docs) reported 56 findings; each was given to a second agent to refute by reproduction: 47 held (45 low, 2 medium, many reported by more than one reviewer; none a way to leak the key or to pass the approval and the Rs 150 total), 9 did not. All 47 were addressed or, where they cannot be closed in code, documented (the key cannot be hidden from code running in the same process, and the ledger is a file in git, so anyone with write access can edit it). Then 41 deliberate breakages of the guards were made one at a time in a copy; the tests catch every one. The reviewers and the author are the same model, not an independent reader; nothing was tested against IK itself except one `meta` call.
