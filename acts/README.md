# acts/ : the Act Directory's review sheet, link tools and evidence

The Act Directory (Recourse `act_directory.py` and `acts_directory.json`, a copy in `../site_patch/`) is step 1 of `../STATUTE_COVERAGE_PLAN.md`: signposts for the Acts whose text Recourse does not hold.

- `ACT_DIRECTORY_SHEET.docx` is for Mr. Advocate: 34 rows (the last four added 2026-10-17; Claude's drafted status line, where appeals go, each with a line "What was read", and a link to click), then a table of the names and short forms that make the site say "names the X Act" and the phrases that make it say "looks like it is about the X Act" (28 Acts; IPC and CrPC are not detected). He is asked to strike any name or phrase that could mean something else.
  Rebuild it from the data with `python acts/build_directory_sheet.py [directory.json] [out.docx]` after the data change.
- Nothing in a drafted column is shown to a user until a person confirms it. In the Recourse checkout: `python act_directory.py confirm ID status|appeal|link --by "Mr. Advocate" [--on DATE]`.
  Claude records only what he answers; it never runs `confirm` on anyone's behalf. An empty draft cannot be confirmed.
- **What the drafts rest on (2026-10-16, after the owner allowed `indiacode.gov.in`):** India Code itself. Each Act's record (repealed or not, enforcement date, amendment list), the footnotes to its sections, and for every appeal line the text of the sections concerned; for the TADA, India Code's PDF of the Act as enacted (read as page images, because its text layer is garbled). Each line has an `evidence` field saying what was read and what is only recollection.
  Reading India Code corrected the first drafts: the TADA's section 1(4) as enacted says two years from 24 May 1987 (the draft said eight; the amendments extended it); the Consumer Protection and Companies Acts' dates were reworded to what India Code says; the PC Act, POCSO and the other priority Acts now name the amending Acts India Code's footnotes cite.
  "certain" in the sheet means "every fact in the line was read on India Code that day", NOT that a lawyer has confirmed it.
- **Links (2026-10-16):** the 23 old-style links (`www.indiacode.nic.in/handle/123456789/<n>`) were stale: on India Code's new system those numbers are other things (`123456789/1558` is a collection called "Form"; `123456789/2079` does not exist). All 30 links are now `https://indiacode.gov.in/items/<uuid>`.
  `resolve_links.py` finds each Act on India Code (850 central Acts, plus the archive entry of a repealed Act) and proposes the link; the Directory's own check then decides: `python act_directory.py check-links [--write]` asks India Code's data API for the record behind each link and requires its title, Act number and year to equal the entry's, central, not withdrawn (a state's version, an amendment Act, a collection or another Act fails; a connection error changes nothing).
  `browser_check.py` opens every link in Chromium and reads the rendered page (the site is a client-side app that answers HTTP 200 for any address, so "the page opens" proves nothing); its report is `link_check_report.json` (30 of 30 show the right Act). A person's click still counts (`confirm ID link`).
- Limits: every status and appeal line is Claude's draft until Mr. Advocate confirms it; the detector finds an Act only when the question names it or uses one of the listed phrases; the Income-tax Act, 2025 is not yet on India Code, so its commencement date could not be read. The measurements are in `../STATUTE_COVERAGE_PLAN.md` ("Status of step 1") and `../test_act_directory_controls.py`.

## The Act shelf (step 2 of `../STATUTE_COVERAGE_PLAN.md`, built 2026-10-16)

- `ACT_SHELF_SHEET.docx` is for Mr. Advocate: nine or ten sections of each of the five loaded Acts (PC Act, POCSO, UAPA, PMLA, SC/ST Act) in full, a column saying why each is on the sheet (the Directory's appeal line cites it, a pointer names it, it answered one of the 75 test questions, or it carries the Act's main offence: Claude's choice, not a statistical sample), the wording the site will show, and three questions only a lawyer can answer. Rebuild it with `python acts/build_shelf_sheet.py --recourse <Recourse checkout>` (the sheet refuses to build if a chosen section is missing or a stated reason no longer holds). A sample check is recorded as a sample; the status of an Act's text stays `machine_checked` ("not yet read by our reviewer") unless he says he has read all of it. Claude records only what he answers.
- The loader, the shelf, its tests and its evaluation are in Recourse (`build_act_chunks.py`, `act_shelf.py`, `act_shelf/`; copies of the code and the small files in `../site_patch/`). India Code's database and its PDF of the same Act can differ in punctuation (the UAPA's defined terms lose their quotation marks in the database): the loader compares words, not punctuation, and lists every correction it applied.
- **2026-10-17, a stricter check (FOLLOW_UPS 2ah).** The loader now also reads every section against the PDF's running text word by word, in order, both ways (`ordered_compare` in `build_act_chunks.py`); the differences it cannot explain stop the load, those the manifest accepts carry a reason (`ordered_accepted`). It found nine defects of India Code's database in the five Acts (a whole proviso of the PMLA's s.44 among them), now corrected. Not on the shelf: the Schedules, the Rules, and the State amendments that India Code prints inside PC Act s.17A, POCSO s.42 and SC/ST s.14 (set aside, a one-line note remains).
- `crosscheck_bns_bnss.py` (read-only; `--recourse <checkout>`; needs `indiacode.gov.in`) reads Recourse's BNS and BNSS chunks against India Code's database and PDF and writes `crosscheck_bns_bnss_report.json`. Every difference that is not a label, an Act number or a chapter heading was read by hand (`VERDICTS` in the script says who was wrong); a new one prints as NOT REVIEWED. It cannot find an error that Recourse and India Code share.
